# 1:1 写实复刻计划

用 Blender 制作按实际尺寸的写实别墅与庭院，在网页保留逐层展开、室内剖切、测距和家具试摆。当前的 Three.js 米制底模已落实平面轴网、各层墙线和图示家具摆位，可作为 Blender 建模的定位底图。

## 实施与验收

1. **外观与庭院。** 按平面图和庭院施工图建立 Blender 米制场景。对照西南、东南、东北三张现场照片匹配视角，先校对体块和门窗，再细化瓦片、木檐、浅米灰外墙、木梯、玻璃栏杆、铺装和庭院设施。交付三个同角度对照视图，核对屋面轮廓、开窗和出入口。
2. **室内与家具。** 按楼层制作洞口、地墙饰面、橱柜洁具和图示家具。以图纸定位家具，按实测尺寸和确认款式补齐细节。二层两处留白按图保留。用俯视图核对墙线和摆位，再看室内视角及通道净宽。
3. **网页交付。** 从 Blender 按楼层、屋顶、庭院和可移家具导出 GLB，使用同一轴网加载写实资产。桌面和手机各实测一次整栋视图、展开、剖切、测距和家具调整。通过后核对 Cloudflare 生产版对应的 GitHub 提交。

## 当前查看器

[尺寸数据](../site/plan.js) 保存主轴、墙线、门窗洞口和家具摆位。庭院可切换施工方案与施工阶段示意。楼层按钮进入单层剖切，平面视图可测水平距离。家具可拖动、按 10 cm 步进微调或旋转 90°，摆位保存在当前浏览器，可恢复图纸布局。
